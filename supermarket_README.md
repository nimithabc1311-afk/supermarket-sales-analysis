# 🛒 Supermarket Sales Analysis

A data analysis project exploring supermarket sales data to uncover trends in revenue, products, customer behavior and branch performance.

## 📌 Project Overview
- Which branch generates the most revenue?
- Which product line sells the most?
- What are the peak shopping hours?
- How do customers pay?
- What is the customer satisfaction rating?

## 📊 Dataset
- **Source:** Supermarket Sales Dataset (Kaggle)
- **Rows:** 1000 transactions
- **Features:** Branch, Product Line, Customer Type, Gender, Payment, Total, Rating, Date, Time

## 🔍 Key Findings
| Insight | Finding |
|---------|---------|
| Top Branch | All branches perform similarly |
| Top Product | Food & Beverages |
| Peak Hours | 10AM-2PM and 6PM-8PM |
| Avg Rating | ~7.0/10 |
| Top Payment | Equal usage of all methods |

## 📈 Visualizations (8 Charts)
1. Revenue by Branch (Bar + Pie)
2. Revenue & Quantity by Product Line
3. Customer Type and Gender Analysis
4. Payment Method Analysis
5. Revenue by Month and Day
6. Hourly Sales Trend
7. Rating Distribution & by Product
8. Correlation Heatmap
